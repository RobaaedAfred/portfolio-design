# Developer Portfolio — React Beginner Project

A complete portfolio project built with React + Vite.

## Run the project

1. Install Node.js 20.19+.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local address shown by Vite in your browser.
